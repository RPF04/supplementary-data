Quick Guide
Download and unzip flowing data:
Code.rar containing:
1.	rasters: raster layers of environmental variables use in MaxEnt modeling
2.	sdm_df: matrices pf environmental variables at presence points of each species and 5000 pseudo-absence points
3.	all.obj: a csv file containing all objects with OWA suitability of land uses
4.	LU_allocation: A R code for land allocation machine learning analysis
5.	MaxEnt_AbbasAbad: A R code to conduct MaxEnt analysis for all species
6.	train.obj: a csv file containing training objects with OWA suitability of land uses

Download and unzip data1 - data5:
1. Paste all .tif files inside 'rasters' folder 
2. Run the Codes
   - Ensure paths in your code point to rasters.  
   - Execute the script.
